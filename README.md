# AI Agent Guardrail

## Project Overview
This project demonstrates the concept of an AI agent guardrail: deciding whether a request should be allowed, rejected, or reviewed before execution.

## Goal
Explore how decision-making can help make AI agents safer and more reliable.

## Planned Technologies
- Strands Decider 2B
- Amazon Bedrock
- Python

## Project Status
Prototype concept. Integration and execution have not yet been verified.

## Intended Use
This repository is a learning demonstration of AI agent guardrails and decision patterns.
